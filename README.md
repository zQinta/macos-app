# zQinta for Mac

The zQinta knowledge-universe app for macOS — build knowledge maps with AI,
generate video + audio for every concept, and publish courses to the
[zQinta Market](https://www.zqinta.com).

## Reporting a bug

Found something broken? Please [open an issue](https://github.com/zQinta/macos-app/issues/new/choose) —
include what happened, what you expected, your app version (menu → About zQinta),
and your macOS version. Diagnostics from **Help → Diagnostics…** help a lot.
